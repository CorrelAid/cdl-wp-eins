FormulAid is a web app based on the Claude Skills standard that generates XLSForm questionnaires from user specifications. This includes searching the question database qwac. The skill is built using content from the Civic Data Lab Umfragenwerkstatt and uses the question types that FormTransform supports. Before download, the app checks every questionnaire with FormTransform and has errors corrected automatically; each question also comes with a reason why it was chosen. The skills used are available here. Users can either provide their own API key for OpenRouter, EUrouter or another OpenAI-compatible provider and use the app in the browser, or import the skills directly into Claude.
